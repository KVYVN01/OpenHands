# Drift Detector

Use `snapshot.sh` at start and after material actions. Use `drift-check.sh` to compare baseline and current state.

## Response to drift
- If expected: add claim and verify.
- If unexpected: pause, report changed files, inspect diff, and correct.
- If generated by tools: record tool command and affected files.
